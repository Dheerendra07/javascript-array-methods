# 💻 Example

```javascript
const fruits = ["Apple", "Banana", "Mango"];

const upper = fruits.map((fruit) => fruit.toUpperCase());

console.log(upper);
// Output:
// ["APPLE", "BANANA", "MANGO"]
```
